## 🌟 Overview

**AgriHarvest** is an AI-driven agriculture platform designed to help farmers make data-informed decisions. It provides intelligent crop recommendations, real-time weather insights, and a digital marketplace — all in one place.

---

## 🎯 Key Features

✨ **AI Crop Recommendation System**
🌦️ **Live Weather Integration**
🧪 **Fertilizer Suggestion Module**
🛒 **Agriculture Marketplace**
🔐 **User Authentication System**
🛠️ **Admin Dashboard**
📊 **Interactive UI & Dashboard**

---

## 🧠 AI Integration

AgriHarvest uses:

* Rule-based intelligent system (JSON-based crop mapping)
* API-ready architecture for real AI models
* Scalable design for ML integration
